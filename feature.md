# 1. Career Discovery

## Objective

Help users identify suitable career paths based on their personality, interests, and strengths.

## User Flow

1. User clicks **"Career Discovery"** from the homepage or dashboard.
2. User selects **Start Assessment**.
3. The system displays a personality & interest assessment (improved Holland + MBTI).
4. User answers all assessment questions.
5. User clicks **Submit**.
6. AI analyzes the responses.
7. The system displays:
   - Personality profile
   - Interest profile
   - Career compatibility map
   - Recommended academic majors
   - Top 3 most suitable career paths
8. User can:
   - View career details
   - Save recommendations
   - Continue to Personalized AI Roadmap

### Main Buttons

- Start Assessment
- Next
- Previous
- Submit
- View Career Details
- Save Result
- Continue to AI Roadmap

- Personality & Interest Assessment Dataset

# 3. Job Simulation

## Objective

Provide realistic work simulations that allow users to experience actual job tasks and receive AI evaluation.

## User Flow

1. User selects **Job Simulation**.
2. Choose:
   - Industry
   - Job Position
3. System displays simulation brief.
4. User completes the assigned task.
5. User submits the work.
6. AI evaluates the submission.
7. Dashboard displays:
   - Overall score
   - Detailed feedback
   - Ranking
   - Improvement suggestions

Companies can also publish real recruitment simulations for candidate assessment.

### Quality Assurance

Simulation tasks are:

- Created directly by partner companies
- Reviewed by professional mentors
- Designed to reflect real workplace scenarios

### Main Buttons

- Choose Industry
- Choose Position
- Start Simulation
- Upload Submission
- Submit
- View Feedback
- Retry

## Supported Industries

1. Accounting & Auditing

3. Information Technology
4. Marketing
5. Logistics

Each industry includes 2–3 job positions.

# 4. Interview Practice

## Objective

Help users prepare for interviews using AI evaluation or one-on-one mentor sessions.

## User Flow

1. User opens **Interview Practice**.
2. Select:
   - General Interview
   - Company-specific Interview Round
3. Choose practice method:
   - Text response
   - Voice response
4. AI evaluates:
   - Answer quality
   - Structure
   - Relevance
5. System displays:
   - Score
   - Feedback
   - Suggested improvements
6. Alternatively, user can:
   - Register as a mentee
   - Schedule a live mock interview with a mentor

### AI Fairness

To reduce evaluation bias:

- AI evaluates response content only.
- Voice, accent, regional background, and gender are **not** used as scoring criteria.
- Scoring criteria are transparent and visible to users.
- Human mentors provide additional evaluation through one-on-one mock interviews.

### Main Buttons

- Choose Industry
- Choose Company
- Start Interview
- Answer by Text
- Answer by Voice
- Submit
- View Feedback
- Book Mentor Session

## Supported Industries

1. Accounting & Auditing
2. Finance & Banking
3. Information Technology
4. Marketing
5. Logistics

Each industry contains 2–3 interview sets based on different job positions.

## Data

- Interview question bank

# 5. Mentor Community

## Objective

Connect students with experienced mentors for career guidance, interview preparation, and professional development.

## User Flow

1. User enters **Mentor Community**.
2. Register as:
   - Mentor
   - Mentee
3. Browse mentor profiles.
4. View:
   - Experience
   - Industry
   - Skills
   - Reviews
5. Send direct messages.
6. Book mentoring sessions.
7. Join the Facebook community.
8. Access updated case studies and career resources from mentors.

### User Retention Strategy

The mentor network encourages long-term engagement by helping users:

- Solve internship challenges
- Receive workplace advice
- Explore new career opportunities
- Access new recruitment case studies
- Receive seasonal recruitment updates via:
  - Platform notifications

  - Facebook Community

# 7. Post-Usage Evaluation & Outcome Tracking

## Objective

Measure the long-term effectiveness of the platform by tracking users throughout their real recruitment journey.

## User Flow

### After Each Feature

The system sends a one-click feedback request asking:

- How helpful was this feature?

### After Completing the Roadmap

The system asks:

- Have you applied for the position you practiced for?
  - Yes
  - No
- Which recruitment stage did you pass?

### After 3–6 Months

A short follow-up survey is sent through mentors asking:

- Employment status
- Job relevance
- Job satisfaction (1–5 scale)

### Long-term Impact Measurement

The platform tracks:

- Application status
- Interview progress
- Offer rate
- Employment status
- Job fit
- Career sustainability

This data helps evaluate the platform's real-world impact beyond user satisfaction.

### Main Buttons

- Rate Feature
- Submit Feedback
- Yes / No
- Select Interview Stage
- Complete Survey

- User feedback questionnaire
- Long-term outcome survey
